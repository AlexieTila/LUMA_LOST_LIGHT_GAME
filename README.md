# Luma: The Lost Light — Godot 4 starter project

Open with **Godot 4.3 or newer** (Project Manager > Import > pick this folder's project.godot).
The first open takes a minute while Godot imports the art. Then press F5.

- Main menu: res://scenes/main_menu.tscn (Play / Settings / Credits / Quit)
- Tutorial level: res://scenes/levels/tutorial_grove.tscn (F6 to run just this scene)

Controls: A/D or arrows = move, Space/W/Up = jump, E or J = Light Pulse, Esc or P = pause.

Folders: art/ (sprites, tiles, UI), scripts/ (all GDScript), scenes/ (all scenes), tools/ (level builder).
To change the level layout: edit LEVEL_MAP in tools/builder.gd, then open tools/rebuild_level.gd and press File > Run.
The step-by-step guide explains every scene and script.
